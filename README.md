# 🗂️ Number Sorter 🔢
Number Sorter is a simple web app built with JavaScript, HTML, and CSS that lets you visualize how sorting algorithms work step-by-step. It helps you understand the logic behind Bubble Sort, Selection Sort, and Insertion Sort by animating comparisons and rearrangements in real time.

## ✅ Key Features

## 🛠️ Tech Stack
- HTML
- CSS
- Javascript, implement and visualize different sorting algorithms:
    - Bubble sort
    - Selection sort
    - Insertion sort 

## ➡️ How to run
Open `index.html` in your browser.
